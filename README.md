# Full Stack System - Database Integration

# Description
Integration of a Node.js backend with Microsoft SQL Server to ensure state persistence and data longevity. It handles complete CRUD operations (Create, Read, Update, Delete) and utilizes Parameterized Queries to shield the database against SQL Injection attacks.

# How to Run
1. Ensure MS SQL Server is running locally on your system.
2. Open the terminal and run `npm install express mssql msnodesqlv8`.
3. Run `node server.js` to start the backend server.
4. Use Thunder Client to test CRUD API requests against the live database vault.
